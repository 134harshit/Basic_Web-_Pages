  • What is HTML ?
    • HTML stands for Hypertext markup language
    • let's take each of those words in sequence hypertext is ordinary text that has been dressed up with extra features ,such as formatting ,image,multimedia and links to other documents.
    • markup is a process of taking ordinary text and adding extra symbols (for example,an editor's proofreading symbols are a type of markup ).each of the symbols used for markup in HTML is a command that tells a browser hoe to display the text .markup can be very simple,or it can be very complicated.either way,the underlying text being marked up is always present and viewable

  • What is CSS ?
    • CSS stands for Cascading style sheets.
    • CSS is a presentation definition language that is used to control the layout of html document by attaching style . with CSS, you can apply style such as colour of text ,set margin , style of fonts ,background image used , spacing between paragraph and words and much more.
