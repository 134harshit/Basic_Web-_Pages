  2. TYPES OF WEB DEVELOPMENT ( "FRONTEND & BACKEND")

    • Frontend = what the customer sees and interacts with .
    • Backend = what happens behind the scenes .


    1. FRONTEND

      2. The frontend is the visible part of an application.

      • It runs on the user's browser/app.
      • It contains buttons, forms, menus, tables, images, etc.
      • It takes input from the user.
      • It sends requests to the backend.
      • It displays the response received from the backend.

      Examples:

      • Login page
      • Register page
      • Product list
      • Product list
      • "Add to Cart" button
      • Dashboard
      • Search box

      Common frontend technologies:

      • HTML → Structure
      • CSS → Design
      • JavaScript → Behavior
      • Angular / React / Vue → Build modern web applications

    2. BACKEND
      3.

      The backend is the hidden part of the application.

      • It runs on a server.
      • It receives requests from the frontend.
      • It contains business logic.
      • It communicates with the database.
      • It validates user input.
      • It performs calculations/operations.
      • It sends data back to the fronten

      Common backend technologies:

      • C# + ASP.NET Core
      • Java + Spring Boot
      • Python + Django/FastAPI
      • Node.js

      For example, in your .NET development:

      Angular → ASP.NET Core Web API → SQL Server
